# Uso de Inteligencia Artificial en el proyecto

Este proyecto ha sido desarrollado como práctica de backend con Node.js, Express y Prisma. Durante el proceso se han utilizado herramientas de inteligencia artificial como apoyo para el aprendizaje, la resolución de dudas técnicas y el avance en el desarrollo.

## 1. Desarrollo del backend

Se ha trabajado en la implementación de la mayor parte de la lógica del backend, incluyendo:

* Estructura del proyecto con controllers, routes y middleware
* Autenticación mediante JWT
* Creación de endpoints para usuarios, productos y categorías
* Integración con Prisma y PostgreSQL
* Lógica CRUD para las distintas entidades

La inteligencia artificial ha sido utilizada como apoyo para:

* Comprender conceptos y patrones de desarrollo backend
* Resolver errores durante la implementación
* Guiar la construcción de funcionalidades
* Mejorar la organización del código

En todos los casos, el código ha sido revisado y comprendido antes de su integración.

## 2. Base de datos y despliegue

También se ha utilizado IA como soporte para:

* Configuración de Prisma con PostgreSQL
* Resolución de errores en migraciones
* Despliegue del backend en Railway
* Configuración de variables de entorno en producción

La configuración final y las pruebas han sido realizadas de forma manual.

## 3. Testing y API

Se ha utilizado IA para:

* Estructurar pruebas de la API con Postman
* Diseñar la colección de endpoints para el testeo del sistema
* Entender el flujo de autenticación y rutas protegidas

## 4. Interfaz frontend (Lovable)

Para la interfaz de demostración se ha utilizado una herramienta de IA generativa Lovable para:

* Generar una web básica conectada al backend
* Crear una interfaz minimalista para la presentación del proyecto
* Facilitar la visualización del flujo completo de la API

## 5. Conclusión

La inteligencia artificial ha sido utilizada como herramienta de apoyo durante el desarrollo del proyecto, principalmente para resolver dudas técnicas, avanzar en el desarrollo, facilitar la comprensión de ciertos aspectos del backend y como base del aspecto final mediante Lovable.
